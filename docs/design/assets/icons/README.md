# Edgy action and split icons

Source: design supplement 2 (artboard S11 for actions, S12 for the split control), generated by
`final-src/26F-1TVB/src/build_supp2.py --svg` in the design vault. Regenerate rather than hand-edit.

- Action icons: 16 x 16 viewBox, 1.5 stroke, round caps and joins, `stroke="currentColor"`, `fill="none"`;
  the only fills (`currentColor`) are the window target regions and the Show Desktop side windows.
- Split drawings: 12 x 40 (vertical, left and right edges) and 40 x 12 (horizontal, top and bottom edges), per BRIEF
  § Split control. Unselected = 1 pt hairline (`line` token); `-selected` = solid fill (`ink` token). 2 pt gaps.
- `ui-advanced.svg` (sliders) is an interface icon, not an action: the Advanced… footer button.
- Keyboard Brightness and Keyboard Backlight On / Off share one drawing (BRIEF icon table), so their files are identical.
