# Security

Edgy has Accessibility access and reads trackpad input, so a security problem in it matters. Please report one privately, not in a public issue.

Open the **Security** tab of this repository and choose **Report a vulnerability**. Only the maintainer sees the report. Include:
- what the problem is and what someone could do with it;
- the Edgy version (About Edgy in the menu-bar popover) and your macOS version;
- the steps to reproduce it.

You'll get a reply within a week. Once a fix ships, we'll credit you in the release notes unless you'd rather we didn't.
