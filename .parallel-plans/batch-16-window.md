## Build
1. **`SettingsWindowView`** — no sidebar. Profile tabs top centre (Default, then per-app tabs with small monochrome app marks, then "+"); the top-right switch follows the tab ("Enabled" on Default, "On in <App>" on app tabs); the mirror (`PadMirrorView`) left, the inspector (`InspectorView`) right; footer row: Haptics, Launch at login, HUD (Native / None), Advanced…. Warm material via `NSVisualEffectView` + `Tokens.windowTint` (provide a small `WindowMaterial` view; headless shots render it flat). Window size and min size chosen so the mirror is to scale for the larger pad and nothing clips at the smaller.
2. **App-profile flows** (§ App profiles): "+" opens the add-app popover (search; Running then All apps from `model.installedApps` (fake in tests); step 2 "Start from": Default, with changes [preselected] / A copy of Default / Empty); tab context menu with Remove and Reset; the legacy note "This profile doesn't follow Default." + Follow Default (`convertToInheriting`); the "Edgy is off in <App>" state.
3. **Window-level states:** § System states (no Accessibility strip with Open Settings that disappears when granted, paused "Paused, N min left" + Resume, no trackpad, disabled faded) and § Issue states (overlapping zones line with Show; broken config: read-only window with Open config file / Reload / "Replace with current settings" behind a confirm — read the state from `editor` once batch 13 lands; until then build against a protocol/fixture in your folder and note it). **Advanced… sheet** plain under the tokens: gesture tuning (edge width, corner size, dwell, palm size, typing suppression, double-tap window, long-press, fingers) with units, haptic events and tick/click strength — every field through `editor.updateGestureSettings` / `updateAppSettings`, ranges from `docs/settings-reference.md`.
