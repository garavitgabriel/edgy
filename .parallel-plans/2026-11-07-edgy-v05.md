## Skeleton already on `main` (chief)

- **`EdgyUI` target** (+ `EdgyUITests`), EdgyApp depends on it. Folders per surface: `Shared/`, `Model/`, `Preview/`, `Mirror/`, `Inspector/`, `Picker/`, `Window/`, `Popover/`, `Overlay/`, `Onboarding/`, `Glyph/`.
- **`Shared/Tokens.swift`** — the BRIEF token table. **The only file in EdgyUI with a colour value, font size or radius literal.** Read everything from `Tokens`.
- **`Model/SettingsModel.swift`** (frozen) — `@Observable @MainActor`: `editor: SettingsEditor` (the one way to change settings — call it directly), `revision`, `selectedProfile`, `selectedZone`, `picking: PickerTarget?`, `engineStatus`, `isTestMode`, `mirroredDevice` (the pad touched last), `liveTouches`, `pendingDecisions`, picker data sources (`installedApps`, `shortcuts`, `keyRecorder`), `startFeed/stopFeed`, `simulate(…)` for previews/tests. Add behaviour in `extension SettingsModel` files **inside your own folder**; need new stored state? Keep it in your views, or write a blocker.
- **`Preview/PreviewFixtures.swift`** — `PreviewFixtures.model()` with the real catalog, a demo config (Default + invented apps "Wayfare" (inheriting: overrides, a turned-off zone, a hold) and "Huddle" (off)), two pad sizes, `MemoryStore`.
- **Stub views** with frozen names + `init(model:)`: `PadMirrorView`, `MiniMirrorView`, `InspectorView`, `ActionPickerView`, `SettingsWindowView`, `MenuPopoverView`, `OnboardingView`; `PlateView` (content enum frozen); `MenuGlyph.State`.
- **`Gestures.PadLayout`** (public) — zone rects in mm and `zone(atMM:mapped:)`, the same geometry the recognizer uses. **The mirror draws from it; never recompute zone math.**
- **Snapshot harness** `Tests/EdgyUITests/Support/Snapshot.swift`: `Snapshot.write(view, folder:, name:, size:)` renders through a real `NSHostingView` at 2×, light + dark, into `docs/design/build-shots/<folder>/`. (An `ImageRenderer` draws system controls as placeholders — don't use it.) Glass material renders flat headlessly; material is judged on the device.
- **Contracts:** `RejectionMeasure` + `GestureOutput.rejectionMeasures`; `ActionOutcome` + `ActionPerforming.performReporting` (default reports nil); `AppSettings.unresponsiveDisplays / confirmedDisplays / displayCheckAsks`; `DisplayInfo.key`.

## Hard rules across all worktrees

1. **Take the time you need.** Correctness > speed.
2. **Verification triple green before DONE**, run in your transcript, plus the denylist.
3. **Stay in your glob.** Need something outside it? Write `blockers-batch-N.md` and STOP on that item; continue the rest.
4. **Never touch the real system from tests** (CLAUDE.md rule 1). UI tests use `PreviewFixtures` — never a live `Engine`, touch source, event tap or real action.
5. **Frozen signatures** (skeleton types and initializers, `makeLive…` factories, EdgyCore contracts) stay exactly as on `main`.
6. **The design is the spec.** Paste BRIEF § Bones into your done report as a checklist, each item ticked with the snapshot file that shows it (or "n/a for this batch"). The kill list is a hard fail. Copy is BRIEF's copy, word for word, where BRIEF gives it.
7. **Token discipline (greps in acceptance):** `grep -rnE 'Color\(red|Color\(\.sRGB|NSColor\(red|NSColor\(srgb|0x[0-9A-Fa-f]{6}|#[0-9A-Fa-f]{6}' Sources/EdgyUI --include=*.swift | grep -v Shared/Tokens.swift` prints nothing; no `.font(.system(size:` / `Font.system(size:` outside Tokens; no `.custom(` fonts; no emoji or Unicode arrows as icons (SF Symbols or drawn shapes only); no second hue (no `.blue`, `.red`, `.orange`, `.yellow`, `.green`, `.accentColor`, `Color.accentColor`).
8. **Review as the reader first.** Before DONE, open your own snapshot PNGs next to the matching `docs/design/final/*.png` and write, per surface, what matches and what differs (and why) in the done report.
9. **Commit small and often**, your branch only. Never `--amend`, never rewrite history, never commit past a failing step.
10. **No third-party product names** anywhere — code, comments, docs, commits, demo data (invented app/display names only, e.g. "Wayfare", "Desk 34").
11. **Own work only.** Outside code is reference for learning, never copied.
12. **Human-only steps** (material over real wallpapers, glyph at real size, feel) are never part of your proof. List them under "Needs Gabriel" and finish.
13. **Close with `/builder-close`.** It must commit ONLY your own return file in the vault (`git add <that one path>`), never `git add -A`. Never reset, revert or rewrite the vault's history.

### Done report schema — `.parallel-plans/done-batch-N.md`

Frontmatter (batch, branch, worktree_path, completed_at, verification), Acceptance criteria, Verification, Bones checklist (UI batches), Reader-first review (UI batches), Diff summary, Decisions I made (and why), Needs Gabriel, Open questions.
