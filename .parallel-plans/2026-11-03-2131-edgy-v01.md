## What we're building

Edgy turns the trackpad's edges and corners into configurable controls. A touch that **starts** in an edge strip or corner can become a slide, swipe, tap, double-tap or long-press, and each (zone, gesture) pair maps to an action from a registry — volume, brightness, mute, mic mute, media keys, run a Shortcut — with per-app profiles. v0.1 is the engine plus a functional menu-bar shell; the settings window and onboarding UI come later from a separate design session.

The product wins on **feel**: no misfires from resting palms, two-finger scrolls near the edge, or the system's own edge swipes, and a cursor that stays still while you slide. Misfire defense is therefore tested against recorded touch traces, not eyeballed.

Pipeline: `TouchSource` (TouchKit) → `GestureRecognizing` (Gestures) → router + profile lookup (EdgyRuntime) → `ActionPerforming` (Actions). While the recognizer reports claimed contacts, the router engages `PointerGuarding` (TouchKit). All contracts are in `Sources/EdgyCore/` and are frozen.

## Platform facts the batches need (verified during research)

- Raw touch: the private `MultitouchSupport.framework` (`/System/Library/PrivateFrameworks/`). Functions used: `MTDeviceCreateList`, `MTDeviceGetFamilyID`, `MTRegisterContactFrameCallback` / `…WithRefcon`, `MTUnregisterContactFrameCallback`, `MTDeviceScheduleOnRunLoop`. Whether `MTDeviceStart` is also required on current macOS is **unknown — test it**. Resolve all of them by name at runtime via `CFBundleCreate` + `CFBundleGetFunctionPointerForName`.
- Hot-plug: IOKit matching notifications on `AppleMultitouchDevice` (first-match + terminate), plus re-enumeration on sleep/wake. No reliable public example exists — this is our own engineering.
- Brightness: private `DisplayServices.framework` — `DisplayServicesGetBrightness` / `DisplayServicesSetBrightness`, built-in/main display only in v0.1.
- Native HUD: NSXPC connection to the `com.apple.OSDUIHelper` service; the method shape is `showImage:onDisplayID:priority:msecUntilFade:filledChiclets:totalChiclets:locked:`. Optional — degrade to no HUD if it fails.
- Volume/mute/mic: public CoreAudio (`AudioObjectGetPropertyData` / `SetPropertyData`) on the default output/input devices.
- Haptics: public `NSHapticFeedbackManager`. No haptics on non-Force-Touch trackpads — must not crash.
- Pointer: hiding/freezing the cursor only works for the foreground app. Reliable method: an **active event tap** that swallows mouse-moved events while engaged, then warps the cursor back to where the gesture began on release. Needs Accessibility.
- Misfire techniques known to work: start-in-zone only; palm gate by contact ellipse size (and size/density outliers); contact-count gate; typing suppression window; dwell **or** along-axis-dominant motion before claiming; perpendicular-inward motion = hand off to the system; velocity gate; hysteresis/dead band on slide output; corners take precedence over edges.
- Distribution (later): Developer ID + notarization + Homebrew cask; not the Mac App Store.

## Hard rules across all worktrees

1. **Take the time you need.** Correctness > speed.
2. **Verification triple green before DONE**, run in your transcript.
3. **Stay in your glob.** Need something outside it (incl. a contract change)? Write `blockers-batch-N.md` and STOP.
4. **Never touch the real system from tests** (CLAUDE.md rule 1). A test that changes volume, brightness, keys, cursor or HUD is a failed batch.
5. **Frozen factory signatures** stay exactly as on `main`; replace bodies only.
6. **Commit frequently**, small commits, your branch only. Never `git commit --amend` or rewrite history.
7. **No third-party product names** in code, comments, docs or commits.
8. **Self-check before DONE:** re-read your diff, confirm every acceptance criterion, then write `done-batch-N.md` (schema below).
9. **Human-only steps** (granting Accessibility, plugging a trackpad, recording traces, feeling haptics) are never part of your proof. Build the script, list the steps under "Needs Gabriel" in your done report, and finish.
10. **Close with `/builder-close`**, never `/end-of-session`.
