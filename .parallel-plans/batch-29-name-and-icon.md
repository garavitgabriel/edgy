## Build (BRIEF is the spec; this is the checklist)
1. **Editor + validation (EdgyRuntime):** one `SettingsEditor` call sets a binding's name and icon as ONE undo step. Name: trimmed, max 24 characters; empty or equal to the action's own name → `nil`. Icon: must be an action ID the icon library draws; the action's own → `nil`. On an app tab, naming an inherited binding creates an override (same action and parameters, new name), shown with the dot and Revert. The engine never reads either field; prove it with a test that a renamed binding performs identically.
2. **Inspector:** the row's "…" menu gets "Name and Icon…" → a popover anchored to the row (≤ 320 pt): Name field (placeholder = the action's own name, focused on open, Return saves), the icon grid (16 pt icons in 28 pt cells, grouped and ordered like the picker with its 11 pt headers, `ink` ring on the selected cell, tooltip "Default" on the action's own), and "Reset name and icon" (quiet `ink2` text button, only when either is set). The row shows the custom name in `ink` with an `ink2` sub-line naming the REAL action and parameter ("Hold Keys: fn Space").
3. **Every surface:** pad tab (custom name replaces the short-form rule; fade when too long, never "…"); zone icons on the mirror and the mini mirror (custom icon); popover hover line ("Bottom-right: Dictate"); plates (the custom name with NO verb: "Dictate"; holds "Dictate, held" → "Dictate, released"; dry run "Would run Dictate"; second line unchanged). The picker always shows real action names.
4. **Hold Keys findability:** when the picker opens for a LONG-PRESS, the Keyboard group moves to the top (above Sound) with Hold Keys first. Other gestures: unchanged.
5. **Performance stays inside batch 28's budgets**: the icon grid and names add no per-frame work (run `scripts/measure-idle.sh` with the popover open; numbers in the done report).
