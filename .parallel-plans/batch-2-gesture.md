# Batch 2 — EDGY-GESTURE: gesture pipeline + misfire defense

Read `CLAUDE.md` and `.parallel-plans/2026-11-03-2131-edgy-v01.md` first. This module is **pure**: no AppKit, IOKit, CoreAudio, timers or clocks — time comes only from frame timestamps.

## Build
1. **Zone geometry** in mm from `TouchDeviceInfo.sensorSizeMM` + `GestureSettings`: edge strips (`edgeWidthMM`), corners (`cornerSizeMM`, take precedence over edges), edge segments (`.edge(e, segment:, segments:)`).
2. **Per-contact tracking** across frames (birth, path, last position/time, origin zone).
3. **Misfire defense**, each step producing a `RejectionReason` when it rejects:
   - start-in-zone only (`startedOutsideZone`); unmapped zones never claim (`disabledZone`);
   - palm gate: major axis > `palmMajorAxisMM`, plus size/density outliers (`palm`);
   - contact count: more simultaneous contacts than `fingers` → reject; 3+ is always the system's (`tooManyContacts`);
   - typing suppression from `GestureContext.secondsSinceLastKeyPress` (`typing`);
   - intent gate for slides: claim only after `dwellMS` of near-stillness **or** clearly along-axis motion; inward perpendicular motion from an edge hands off (`systemGestureHandoff`), other off-axis motion rejects (`offAxisMotion`); an initial flick faster than a threshold is a swipe candidate, not a slide (`tooFast` only if neither);
   - hysteresis / dead band so slide output doesn't jitter at rest.
4. **Recognizers**: slide (began/changed/ended with normalized `delta` along the zone, sign: toward top/right is positive), swipe (direction), tap (short + low travel), double-tap (`doubleTapWindowMS`), long-press (`longPressMS`, low travel). Corners: taps/double-taps/long-press only.
5. `GestureOutput.claimedContactIDs` is non-empty exactly while a slide/long-press owns a finger.
6. `makeGestureRecognizer()` returns the real implementation.
7. A test-only `TraceBuilder` helper to synthesize realistic frame sequences (positions in mm, 120 Hz timestamps, configurable ellipse).
